# v1.2.40 - Continuous Neural Recall Maintenance

## Added

Added `db/neural_recall_continuous_maintenance_2026_05_20.sql`.

Added `memory_neural_continuous_maintenance(...)` for bounded local ANN

backfill, ranked-result feedback scoring, alias refresh, ANN-neighbor semantic edge creation, stale derived model embedding cleanup, runtime metrics, and search-surface refresh.

Added `scripts/neural_memory_maintenance.py` as the production maintenance

runner. It calls the SQL maintenance function, runs one semantic-worker batch, and backfills a bounded number of real local embeddinggemma model vectors.

## Changed

Moved MemoryDB neural/vector recall from one-time backfills toward continuous

retraining of derived surfaces.

Added automatic `neural_rank_positive` and `neural_stale_penalty` retrieval

feedback rows from ranked recall result telemetry.

Added automatic `ann_nearest_neighbor` semantic edges from pgvector-near

records so related memories can reinforce each other beyond exact text.
