# Zorg MemoryDB v1.2.4

Released: 2026-05-07

## Focus

This release adds a public-safe "Before You Get Started" guide so new users understand what accounts, API keys, OAuth tokens, hosting decisions, and private backup access they should prepare before installing Zorg MemoryDB.

## Added

- New `docs/before-you-get-started.md` guide covering local vs hosted deployment, model provider keys, messaging tokens, Google/Gmail OAuth, Microsoft Graph mail authorization, other mail providers, GitHub access, private backup repositories, Cloudflare Tunnel, Docker, and Dockge.
- README link and short pre-install section pointing users to the new checklist.
- `.env.example` placeholders for OpenRouter, OpenAI, messaging, email OAuth, GitHub backup, and Cloudflare token configuration.

## Clarified

- OpenRouter is documented as a practical minimum model-provider path.
- OpenAI API is documented as the recommended entry-level production baseline.
- Dedicated assistant email plus operator CC remains the recommended executive-assistant email pattern.
- Private GitHub/off-host recovery is described as core preparation, not an afterthought.

## Privacy

No private API keys, OAuth tokens, GitHub tokens, mailbox contents, database dumps, internal hostnames, contact data, transcripts, or operator context are included.
