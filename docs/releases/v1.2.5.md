# Zorg MemoryDB v1.2.5

Released: 2026-05-07

## Focus

This release clarifies that individual recipient rules override default email-copy behavior and that scheduled jobs should be phrased as LLM instructions, not blind automation.

## Added

- Public-safe individual email-copy hierarchy guidance for executive-assistant installs.
- `OPERATOR_BCC_RECIPIENTS` placeholder for recipient-specific BCC exceptions.
- Public-safe guidance that cron jobs should be natural-language LLM instruction jobs with context, checks, and stop conditions.

## Changed

- Updated the shared rich-email helper template so configured recipient-specific BCC exceptions can override default operator CC behavior.

## Privacy

No private recipient names, email addresses, tokens, database rows, transcripts, credentials, or operator context are included.
