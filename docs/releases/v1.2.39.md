# v1.2.39 - Host Docker and Dockge Upgrade Runbook

## Changed

Added a separate host Docker Engine and Dockge manager upgrade runbook so

infrastructure upgrades are not mixed with OpenClaw/Zorg stack upgrades.

Updated Docker Compose and Dockge install docs to use Docker's official Ubuntu

apt repository instead of Ubuntu's `docker.io` package.

Added warnings against using Docker's convenience script for existing

production upgrades.

Added Dockge manager upgrade guidance to run `docker compose pull` and

`docker compose up -d` from `/opt/dockge` over SSH/terminal instead of self-updating Dockge from inside the Dockge UI.

Linked the new host infrastructure upgrade path from the main upgrade chooser

and README.

## Verification

Rechecked Docker's official Ubuntu install/upgrade documentation before

changing Docker package guidance.

Rechecked Dockge's upstream README before documenting the manager update path.

Tested the host Docker package upgrade on the AIDJStudio Ubuntu 22.04 VM:

Docker upgraded from `29.4.2` to `29.5.1`, Docker stayed active, Dockge remained healthy, and the Dockge-managed OpenClaw/Zorg stack restarted.

Tested Dockge manager update from `/opt/dockge` with

`docker compose config`, `docker compose pull`, and `docker compose up -d`; Dockge continued responding on port `5001`.
