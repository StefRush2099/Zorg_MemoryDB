# Zorg MemoryDB v1.2.60

This release hardens the public Zorg Memory 3D package boundary.

- Bumped `zorg-memory-3d` to `0.2.0`.
- Reworked the public visualizer to discover local PostgreSQL metadata at
  runtime instead of shipping a built-in private structure.
- Removed private graph-shape assumptions from the public Memory 3D server and
  UI copy. Installs can expose their own local structure dynamically without
  publishing that structure to GitHub.
