# Zorg MemoryDB v1.2.47

## Fixed

- Updated the Docker gateway bootstrap so host-side openclaw tui connections to the published gateway port work with token authentication. Docker-published connections arrive at the gateway from the Docker bridge instead of true localhost, so the container now explicitly enables insecure local Control UI compatibility and device-auth bypass for this token-protected Docker path.

## Notes

- Set OPENCLAW_CONTROL_UI_DISABLE_DEVICE_AUTH=false before container startup if the deployment uses HTTPS or a paired browser/device identity and should keep OpenClaw's default Control UI device-auth requirement.
