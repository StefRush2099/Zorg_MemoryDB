# Zorg MemoryDB v4.1.1

This corrective release makes the public package self-contained for clean installs and in-place upgrades.

- Adds the missing PostgreSQL core scheduler tables, run history, due-time calculator, claim/finish/execute chain, SQL runner, semantic worker, health function, trigger, and the two documented core job seeds.
- Reconciles the two named pg_cron firing jobs idempotently so rerunning the installer cannot accumulate duplicates.
- Ships the repaired LLM dispatcher contract: `payload.text` is authoritative, a distinct `payload.message` is appended as an amendment, and only a job with both fields empty is rejected.
- Makes Control UI device-auth disabling an explicit compatibility opt-in instead of the default.
- Fails closed when required host prerequisites remain unavailable.
- Expands package verification to reject missing scheduler dependencies, seeds, installer wiring, or dispatcher prompt regressions.

The release contains public-safe schema, code, documentation, and verification assets only. It contains no operator memory rows, credentials, prompts, contacts, or installation-specific state.
