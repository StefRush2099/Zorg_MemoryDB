# v1.2.59

## Built-In Zorg Memory 3D

Zorg MemoryDB standard installs now include `zorg-memory-3d` as a built-in
native service.

- Added `zorg-memory-3d/` to the base install files.
- Added `scripts/install_zorg_memory_3d.sh` to install the brain map as
  `zorg-memory-3d.service`.
- Updated the Standard Ubuntu installer and existing OpenClaw overlay upgrade
  helper to copy, install, and start the brain map.
- Documented the map and ADMIN page in `docs/zorg-memory-3d.md`.
- Added current screenshots for the map and ADMIN settings page under
  `docs/assets/`.

Default native URLs:

```text
http://127.0.0.1:8097/
http://127.0.0.1:8097/admin
```

The Standard Ubuntu path runs Zorg Memory 3D as a native Node.js service, not a
Docker container.
