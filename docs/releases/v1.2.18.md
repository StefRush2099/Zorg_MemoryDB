# v1.2.18 - 2026-05-18

This release removes the remaining incorrect Docker Compose local-mode chat guidance from current docs and release notes.

## Changed

Removed the bad Docker Compose chat command from README, Docker install, Dockge install, quickstart, historical release notes, and changelog text.

Kept the installed Docker Compose Control UI path on `docker compose port openclaw 18789` so users open the actual host-published Gateway port.

Corrected the installed Docker Compose TUI path to `docker compose exec -it openclaw openclaw tui` so users attach to the already-running Gateway container instead of creating a one-shot helper container.

## Verification

Rechecked official OpenClaw Docker, dashboard, and TUI docs first.

Verified upstream OpenClaw documents `chat` as an alias for embedded local TUI mode, not the installed Docker Gateway path.

Verified current docs no longer contain the bad Docker Compose chat command, stale dashboard helper command, or one-shot Compose-run TUI command as current guidance.

Validated `docker compose --profile cli config`.
