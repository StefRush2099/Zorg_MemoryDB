# zorg-db-memory v1.2.68

This release corrects the public GitHub positioning for Zorg MemoryDB.

Zorg MemoryDB is an add-on package for OpenClaw-based assistants. It is not a GitHub fork or vendored source copy of OpenClaw.

## Changed

- Updated package metadata to v1.2.68.
- Clarified README and OpenClaw base documentation so the repository is described as a Zorg MemoryDB package layer, not an OpenClaw fork.
- Extended the `zorg-db-memory` GitHub posting/release rule to include GitHub repository metadata and fork-network verification.
- Required future release checks to verify `isFork`, parent, repository description, homepage, topics, default branch, visibility, rendered pages, release notes, and release assets before claiming a GitHub publication is complete.

## Verification

- Backend PostgreSQL/Zorg MemoryDB recall must pass before publication.
- Public package verification must pass.
- The release archive must contain the v1.2.68 metadata and the updated GitHub posting/release rule.
- GitHub repository metadata must show the corrected description, homepage, topics, default branch, public visibility, and no active OpenClaw fork parent.
