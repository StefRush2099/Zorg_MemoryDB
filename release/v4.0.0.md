# Zorg MemoryDB v4.0.0

This is a major release of the connected Zorg MemoryDB package.

- The native `zorg-memorydb` OpenClaw plugin/MCP is the first and canonical
  initialized durable-memory path.
- All release-owned package, plugin, MCP, LAN Command Chat, lockfile, and gauge
  metadata is aligned to `4.0.0`.
- The repository documents the supported command-line install from the tagged
  GitHub release.
- Previous Zorg package/plugin files are removed during upgrade while the
  PostgreSQL source database is preserved.
- Markdown memory/rule creation, copying, importing, and fallback activation
  are removed from the install path.

No installation test is performed by the publisher. The recipient installs and
tests the tagged release on a separate system.
