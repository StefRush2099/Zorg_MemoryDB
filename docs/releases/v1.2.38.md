# v1.2.38 - Docker Upgrade Cache Busting

## Changed

Corrected Docker Compose and Dockge upgrade docs so upgrades force a clean image rebuild with `--pull --no-cache --build-arg OPENCLAW_VERSION=latest` before recreating the `openclaw` service.

Added explicit version verification inside the running Docker container after the rebuild.

Added a warning in the upgrade chooser that plain `docker compose up -d --build` can reuse the cached `openclaw@latest` install layer and leave old OpenClaw code running.

Removed PostgreSQL 16 `psql` dump guard meta-commands from `db/schema.sql` so Docker and Dockge first-run schema import works with the PostgreSQL 15 client currently installed in the container image.

Added pgvector `v0.8.1` installation to the OpenClaw/Zorg Docker image so the bundled ANN recall schema can create the required `vector` extension on clean installs.

Qualified first-run recall refresh calls with the `public` schema so they work after the schema dump clears `search_path`.

Qualified bundled recall refresh function bodies in `db/schema.sql` so they refresh materialized views correctly after the dump clears `search_path`.
