# zorg-db-memory v1.2.72

This release publishes the connected LAN Command Chat gauge update and the
Memory Brain 3D view that was previously present only on an unreleased branch.
The release number is advanced so checkout and update checks can detect the
change.

## Changed

- Publishes the current LAN Command Chat gauge UI, live PostgreSQL readouts,
  gauge persistence, and the Memory 3D toggle.
- Publishes the connected Memory Brain 3D source bundle used by that view.
- Installs Memory Brain 3D alongside LAN Command Chat using the configurable
  `MEMORY_3D_DIR` path.
- Restores the real request-to-response `Time summary:` requirement.
- Rejects fabricated backend-scan timing and caller-supplied timing values.
- Preserves the mandatory PostgreSQL/Zorg MemoryDB recall and repair gate.
- Bumps the package release from `v1.2.71` to `v1.2.72`.

## Verification

- LAN Command Chat TypeScript compilation and production build pass.
- Memory Brain 3D JavaScript syntax checks pass.
- Public package verification passes.
- Release tag points to the gauge-bearing main branch commit.
- A fresh checkout sees `v1.2.72` as newer than `v1.2.71`.
