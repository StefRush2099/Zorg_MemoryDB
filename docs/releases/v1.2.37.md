# v1.2.37 - Real Model Embedding ANN Layer

## Added

Added `memory_ann_model_embeddings` for real model embedding vectors.

Added `memory_query_embedding_cache` so query embeddings can be generated by OpenClaw and reused by SQL recall.

Added `memory_provider_ann_recall(query, limit)` for model-vector nearest-neighbor recall.

Updated weighted recall to include `model_embedding_ann` ahead of the local hash-vector fallback.

Added `scripts/backfill_openclaw_model_ann_embeddings.mjs` to backfill real OpenClaw embedding provider vectors into pgvector.

## Verification

Repaired the local OpenClaw embedding provider by installing the missing `node-llama-cpp` optional dependency.

Verified the active local model returns 768-dimensional embeddinggemma vectors.

Backfilled an initial 16 real model embedding rows and cached 3 query vectors.

Verified weighted recall returns `model embedding ANN match` and nonzero `model_embedding_ann` scores under a 5 second statement timeout.

The prior OpenAI key path was tested and found invalid; it was not used for production embeddings.
