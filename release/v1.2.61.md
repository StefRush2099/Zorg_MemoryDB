# Zorg MemoryDB v1.2.61

## Summary

This release reshapes the public repository into a focused Zorg MemoryDB package on top of OpenClaw instead of a full OpenClaw source fork.

## Changes

- Adds the live `zorg-db-memory` skill as the canonical packaged skill.
- Keeps OpenClaw as the base install and references upstream OpenClaw instead of vendoring full OpenClaw source.
- Keeps public-safe Zorg MemoryDB package code under `package/zorg`.
- Removes upstream OpenClaw implementation/build/test directories from the current public tree.
- Adds public package documentation, install notes, screenshot index, and release notes.
- Adds Memory Brain 3D screenshots for desktop and mobile, light and dark modes.
- Adds LAN Command Chat screenshots showing the Memory 3D toggle panel inside the app.
- Documents consolidated skill features: DB-first recall, markdown lockout, Rule Zero repair, context-window DB slicing, PostgreSQL install/recovery, semantic routing, LAN Command Chat support, and Memory Brain 3D support maps.
- Removes public package instructions that could make installed agents publish back to this GitHub repository.
- Excludes secrets, live database rows, DB dumps, `node_modules`, build output, browser profiles, and runtime-private artifacts.
