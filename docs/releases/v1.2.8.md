# Zorg MemoryDB v1.2.8

## Summary

This release adds automatic external host-port selection for Docker Compose and Dockge installs. If the default external OpenClaw port is already in use, Docker selects the next available port from the configured range.

## Changed

- Added `OPENCLAW_GATEWAY_PUBLISHED_PORTS`, defaulting to `18789-18889`, for the external host port range.
- Added `OPENCLAW_GATEWAY_CONTAINER_PORT`, defaulting to `18789`, for the internal OpenClaw listen port.
- Updated Compose to publish `OPENCLAW_GATEWAY_PUBLISHED_PORTS:OPENCLAW_GATEWAY_CONTAINER_PORT` so Docker can automatically choose the first free host port.
- Updated Docker, Dockge, and quickstart docs to tell users to check `docker compose ps` or `docker ps` for the selected port.

## Verification

- Docker Compose configuration validates with the default published range `18789-18889:18789`.
- A live collision test with `18789` occupied confirmed Compose selected the next available host port automatically.

## Privacy

This release publishes only public-safe installer, Compose, and documentation changes. It does not include private memory rows, database dumps, contacts, emails, transcripts, credentials, live account data, internal hosts, or operator context.
