# v1.2.43 - Recall release catch-up and semantic worker robustness

Released: 2026-05-21

## Changed

Published the accumulated public-safe MemoryDB design updates since the last GitHub Release, including pgvector ANN recall, real model embedding recall, continuous neural recall maintenance, markdown statement recall, dynamic logic-rule ranking, dynamic performance benchmarks, public-safe logic-rule seeds, and cleaner first-run bootstrap behavior.

Hardened `scripts/memory_semantic_worker.py` so semantic nodes are acquired in a stable order across workers, reducing avoidable lock contention during concurrent queue processing.

Wrapped each claimed semantic work queue job in a PostgreSQL savepoint so one bad row is marked failed without aborting later jobs in the same claimed batch.

Updated recall and backpressure documentation to describe the worker's deterministic node ordering and per-job failure isolation.
