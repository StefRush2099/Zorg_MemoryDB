# Zorg MemoryDB v4.1.4

This source release removes fixed-address dependencies from LAN Command Chat.

## LAN dynamic-address correction

- LAN Chat listens on `0.0.0.0:3001`.
- nginx listens generically on port 80 and no longer contains fixed private
  addresses, fixed `/24` client networks, or an address-based `deny all` gate.
- Application password/session authentication remains required.
- The machine hostname/mDNS route is the human-facing address, so DHCP or
  interface-address changes do not require application configuration changes.
- The release verifier rejects fixed client addresses/subnets in packaged LAN
  nginx configuration.
- The live UI was built in staging, loaded through a controlled LAN-only
  restart, authenticated, visually inspected, and captured with a rendered
  v4.1.4 gauge.

The installed OpenClaw connector was not patched, installed, reloaded, or
restarted.

External OpenClaw installation, upgrade, recovery, rollback, restart, and runtime-registration acceptance: pending a separately supplied test host.

Official nginx access-module documentation:
https://nginx.org/en/docs/http/ngx_http_access_module.html
