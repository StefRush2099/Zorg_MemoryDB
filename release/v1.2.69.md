# zorg-db-memory v1.2.69

This release syncs the public Zorg MemoryDB package with the latest canonical
DB-first memory skill behavior.

## Changed

- Added DB-first fact-summary and explicit GO-gate guidance to `zorg-db-memory`.
- Added additive ANN/vector recall tuning guidance, including explicit handling
  for ANN misses and query observations.
- Updated MemoryDB Python tools, including the installer-copied runtime tools,
  to call DB-owned recall/search/semantic helper procedures instead of carrying
  large SQL blocks in Python.
- Added public-safe PostgreSQL migration files for the stored-procedure recall
  API, bounded recall paths, semantic source lookup, table/search helpers, and
  generic due-job enqueue support.
- Kept the GitHub repository metadata and fork-network verification safeguards
  introduced in v1.2.68.
