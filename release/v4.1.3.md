# Zorg MemoryDB v4.1.3

This corrective source release establishes a hard separation between release
authoring and connector installation testing.

## Source-system protection

- The candidate connector was not installed, linked, activated, copied into,
  or tested through the active OpenClaw installation.
- OpenClaw configuration, plugin slots, Gateway state, and the installed
  connector were not changed, reloaded, or restarted for this release.
- Source verification was limited to compilation, unit/static checks,
  installer syntax, version parity, package/archive inspection, privacy and
  secret scans, and remote GitHub verification.
- LAN Command Chat was treated as a separate authorized surface. Its packaged
  and live source/build gauge markers were synchronized to v4.1.3. The live
  service restart and authenticated rendered-gauge proof remain pending because
  the service manager requires operator authentication.

External OpenClaw installation, upgrade, recovery, rollback, restart, and runtime-registration acceptance: pending a separately supplied test host.

This release must not be described as installation-verified until a separate
target produces the required private acceptance receipt.
