# Zorg MemoryDB v2.0.18

This patch release adds stale-embedding invalidation to the skill-owned rule
scope migration. Active ANN entries are now disabled when their stored content
hash no longer matches the current active rule, preventing superseded rule text
from re-entering semantic recall.

The root package and LAN Command Chat gauge are both versioned at `2.0.18`.
Private memory, credentials, database contents, local connection maps, retired
runtime artifacts, and generated build output remain excluded.
