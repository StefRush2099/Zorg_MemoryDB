# zorg-db-memory v1.2.70

This release removes generated database passwords from the default local
installer path.

## Changed

- Creates the local `zorg` PostgreSQL role without a password.
- Configures passwordless PostgreSQL access only on loopback when the installer
  has permission to update `pg_hba.conf`.
- Writes blank password configuration and passwordless local connection URLs.
- Rejects unauthenticated remote PostgreSQL configuration instead of exposing
  the database to the network without credentials.
- Documents the authentication boundary for clean installs.

## Verification

- Shell syntax check passes for the installer.
- Public package verification and archive scans pass.
- PostgreSQL/Zorg MemoryDB recall and health checks pass before publication.
