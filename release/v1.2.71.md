# zorg-db-memory v1.2.71

This release removes operator-specific filesystem assumptions from the
published MemoryDB support package and keeps LAN Command Chat and Memory Brain
3D on the same PostgreSQL configuration contract.

## Changed

- Resolves worker and tool paths from `OPENCLAW_WORKSPACE`/`WORKSPACE_DIR` and `SQL_MEMORY_MAP`/`ZORG_SQL_MEMORY_MAP`.
- Makes installer, backup, recovery, dispatcher, and OpenClaw binary paths configurable.
- Makes LAN Command Chat use the configured workspace, sessions directory, OpenClaw binary, and SQL map.
- Makes Memory Brain 3D load the shared SQL map before explicit `PG*` fallbacks.
- Adds a skill contract requiring LAN Command Chat and Memory Brain 3D verification for MemoryDB updates.

## Verification

- Python and shell syntax checks pass.
- Vorg variable resolution selects `/home/vorg/.openclaw/workspace/sql_memory_map.json` when explicitly configured.
- LAN Command Chat TypeScript compilation passes; lint reports only existing warnings.
- Memory Brain 3D syntax check passes.
- Public package scan, PostgreSQL table check, and MemoryDB speed test pass.
