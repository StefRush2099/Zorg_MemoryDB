# Zorg MemoryDB v1.2.57

## LAN chat and full public rule seed

This release fixes two install gaps in the public Zorg MemoryDB overlay.

## Changed

- `lan-chat` now replaces the main Conversation tile with a tmux-backed web
  command line that opens the local `openclaw tui`.
- The LAN chat UI keeps the runtime status, current activity, PostgreSQL gauge,
  live query, browser audio, and Zorg Memory 3D readouts visible around the TUI
  command surface.
- `db/public_canonical_rules_update_2026_06_02.sql` now seeds the full
  public-safe canonical rule set: 93 active rules scoped as `public_safe` or
  `public_safe_only`.
- The public canonical rule SQL now verifies the 93-rule count after applying
  the seed and fails if that full public set is not present.
- `scripts/first_run.sh` and `scripts/upgrade_existing_openclaw.sh` apply the
  public canonical rule SQL after the base schema.
- `scripts/upgrade_existing_openclaw.sh` now installs the built-in LAN command
  chat automatically after DB-memory verification. Set
  `ZORG_SKIP_LAN_CHAT_INSTALL=1` only when intentionally skipping that surface.

## Verification

- Verified the latest Vorg Memory 3D tree matches the local OpenClaw Memory 3D
  tree, then checked local Memory 3D health and graph data.
- Verified the native LAN chat build, `lan-chat.service`, `/api/tui`,
  `/api/chat/status`, `/api/chat/activity`, `/api/db/status`, and
  `/api/db/queries`.
- Confirmed the source DB has 93 active public rules across `public_safe` and
  `public_safe_only`.
- Regenerated the public-safe SQL seed from those public-scoped rows only.
- Rechecked GitHub documentation for pull request checks and Actions log
  inspection before preparing this repository update.
