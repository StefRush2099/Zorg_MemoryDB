# Zorg MemoryDB v3.0.5

This release publishes the canonical OpenClaw-native plugin and standalone MCP
server for the PostgreSQL-backed Zorg MemoryDB.

## Install and upgrade contract

Install OpenClaw from its official distribution, PostgreSQL with the required
extensions, the configured local embedding provider/model, and Node.js/npm.
Install the complete Zorg package, apply every SQL migration under
`package/zorg/db`, install the plugin from
`skills/zorg-db-memory/plugin-src`, enable it, restart the Gateway, and verify
the runtime with `openclaw plugins inspect zorg-memorydb --runtime --json`.

When upgrading from another Zorg version, remove 100% of the previous Zorg
package/plugin files before installing this release. Preserve only the
PostgreSQL backend database; apply the included migrations and ANN/vector
repair scripts to that database. Do not preserve retired launchers, disabled
copies, old plugin roots, generated directories, or legacy compatibility files.

The first clear-channel announcement after an update is mandatory:
`I have just updated to Zorg MemoryDB 3.0.5.`

## Verification

The release gate requires package sanitization, version/gauge alignment,
plugin build and runtime inspection, MCP startup, PostgreSQL table/search and
speed checks, scheduler catalog comparison, ANN/vector index/cache/weight
repair with a real ANN hit, LAN Command Chat, Memory 3D, and clean-install and
upgrade-path checks. Private database rows, credentials, dumps, and local
configuration are not included.
