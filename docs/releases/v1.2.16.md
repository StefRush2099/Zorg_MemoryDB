# v1.2.16 - 2026-05-18

This release fixes the Docker TUI correction that still described embedded local mode for installed Docker Gateway users, and adds the missing upgrade runbook.

## Changed

Docker Compose, Dockge, and Docker run docs now distinguish Gateway-connected Docker TUI startup from embedded local mode.

Docker Compose `openclaw-cli` now shares the network namespace of the running service named `openclaw`, matching upstream OpenClaw's Docker sidecar pattern.

Install docs now link to a dedicated upgrade runbook.

## Added

Added `docs/upgrading.md` with Docker Compose, Dockge, Docker run, existing plain OpenClaw workspace, verification, and rollback guidance.

The upgrade runbook links its authoritative basis to official OpenClaw updating docs, official OpenClaw Docker docs, and upstream `openclaw/openclaw` source.

## Verification

Compared commands against official OpenClaw updating and Docker documentation.

Compared TUI behavior against upstream `docs/cli/tui.md`, `docs/web/tui.md`, and `src/cli/tui-cli.ts`.

Validated `docker compose --profile cli config`.

Superseded by current docs for Control UI URL discovery: use `docker compose port openclaw 18789` to print the selected host port.
