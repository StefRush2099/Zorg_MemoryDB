# v1.2.32 - Neural Recall Feedback Layer

Public-safe structural update for DB-memory recall.

## Added

`db/neural_recall_layer_2026_05_18.sql`

`memory_neural_query_results` for query/result scoring feedback.

`memory_neural_entity_aliases` for indexed semantic-node aliases.

Pending `memory_embedding_slots` backfill for recall hints, semantic nodes, canonical contacts, and operational facts.

Additional indexes for active semantic-edge, recall-hint, query-feedback, alias, and embedding-slot lookups.

## Changed

`zorg_recall_context(query, limit)` now combines source priority, text match, recency, current/corrected evidence, stale/bad penalties, semantic-edge signals, query observations, and recall hints.

Non-empty recall queries record lightweight ranked feedback and enqueue bounded neural-query feedback work.

`scripts/memory_semantic_worker.py` now consumes `neural_query_feedback` jobs and turns ranked query results into weighted semantic edges and useful query observations.

## Safety

Additive only: no source memory rows are deleted, pruned, truncated, compacted, or aged out.

No cron jobs are introduced.

Worker processing remains bounded through the existing semantic work queue and dynamic batch controls.

Full production DB backup is required before applying this migration.
