# v1.2.23 - Beginner Install Labels

Released: 2026-05-18

## Changed

Added bold beginner-facing labels across the install docs for **assistant install folder**, **Dockge stack folder**, **container/service**, **container name**, **image**, and **state folder**.

Clarified that customer-visible folders should use assistant names such as `front-desk-assistant`, not MemoryDB implementation names.

Updated standard Ubuntu install wording to follow the official OpenClaw one-command install formula: paste one command, run it, then open OpenClaw.

Added explicit Dockge paste-only stack naming guidance so the stack name shown in Dockge matches the assistant being created.

## Verification

Docker Compose configuration validated with `docker compose --profile cli config`.

Documentation scanned for the new beginner labels and remaining confusing MemoryDB-style folder examples.
