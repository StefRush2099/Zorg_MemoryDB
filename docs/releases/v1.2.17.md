# v1.2.17 - 2026-05-18

This release corrects the Docker Compose Control UI and TUI documentation for the Zorg MemoryDB package.

## Changed

README, Docker install, Dockge install, quickstart, and upgrade docs now use `docker compose port openclaw 18789` to discover the actual Control UI host port.

Gateway-connected TUI docs use `docker compose exec -it openclaw openclaw tui`.

Removed incorrect local-mode chat guidance from current docs because upstream OpenClaw documents `chat` as embedded local mode.

## Verification

Rechecked official OpenClaw Docker docs and upstream `openclaw/openclaw` Compose sidecar behavior.

Verified upstream OpenClaw TUI docs: `openclaw chat` is an alias for `openclaw tui --local`, not the installed Docker Gateway path.

The installed Docker Gateway TUI path runs `docker compose exec -it openclaw openclaw tui`.

Validated `docker compose --profile cli config`.

The Control UI host port is discovered with `docker compose port openclaw 18789` because this package publishes a dynamic host port range.
