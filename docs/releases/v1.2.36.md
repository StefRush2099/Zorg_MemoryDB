# v1.2.36 - pgvector ANN Recall Layer

## Added

Added a pgvector-backed ANN recall layer with `memory_ann_embeddings`, HNSW cosine indexing, and `memory_ann_recall(query, limit)`.

Added deterministic local hash embeddings (`local-hash-v1-384`) as a rebuildable bridge until provider embeddings are configured.

Added `memory_retrieval_feedback` so positive and negative retrieval feedback can adjust ranking without deleting source history.

Updated weighted recall scoring to combine hard-rule priority, text/FTS/trigram recall, recency, graph edges, recall hints, query observations, pgvector ANN score, and retrieval feedback.

Added a reusable `docker/postgres-pgvector/Dockerfile` so PostgreSQL containers can be rebuilt with pgvector extension files already present.

## Verification

Live DB has pgvector extension `0.8.1` enabled.

Backfilled 28,240 active ANN embeddings from the unified memory search surface.

Verified weighted recall for the idle context pruning rule returns pgvector ANN scoring in `weight_breakdown` under a 5 second statement timeout.

Source memory rows and existing `memory_embedding_slots` remain intact.

Built local image `local-postgres-pgvector:16` from the same Dockerfile pattern for container-rebuild durability.
