# Zorg MemoryDB v4.1.5

This release makes mandatory MemoryDB startup deterministic and fail closed.

- The plugin no longer imports the race-prone OpenClaw ESM tool-plugin helper
  during parallel gateway bootstrap. It uses the stable plugin API supplied to
  its registration entry point.
- Exact-turn receipts record and require the complete mandatory rule set.
- Visible responses are rejected when their required elapsed-time proof is
  missing, duplicated, misplaced, or malformed.
- The packaged startup verifier rejects an unenforced gateway when plugin load,
  PostgreSQL identity, receipt-table, or mandatory-rule checks fail.
- Neural Recall Activity categories and assignments are owned by PostgreSQL and
  exposed dynamically through the plugin, MCP server, and graph response.
- The destructive public-baseline preparation helper is no longer distributed.

The candidate was compiled, unit-tested, scanned, and packaged on the source
system. It was not installed, activated, reloaded, or runtime-tested there.

External OpenClaw installation, upgrade, recovery, rollback, restart, and runtime-registration acceptance: pending a separately supplied test host.
