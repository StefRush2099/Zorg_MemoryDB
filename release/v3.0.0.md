# Zorg MemoryDB v3.0.0

This major release publishes the connected MemoryDB package.

It includes the complete public-safe source-record capture layer, including
turn manifests, individual event occurrences, immutable payload blobs, capture
gaps, code artifacts, code before/after/patch files, tool/model payloads, and
event provenance. Derived semantic and ANN structures are included as linked,
rebuildable recall layers: queued semantic processing, embeddings and
provenance, exact-repeat groups, weighted relationships, recall hints, and
autoheal.

The release also includes the LAN Command Chat integration and its shared
PostgreSQL configuration contract, the current `zorg-db-memory` skill, all
public-safe migrations/install procedures, and verification gates. Private
credentials, host-specific secrets, operator data, and generated artifacts are
excluded by the public-package verification gate.
