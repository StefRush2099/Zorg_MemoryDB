# v1.2.44 - Native Ubuntu first-run hardening

Released: 2026-05-21

## Changed

Hardened `scripts/install_standard_ubuntu.sh` from the 10.2.69.113 first-run install findings:

skips Ubuntu's separate `npm` package when NodeSource Node already provides npm

installs pgvector from apt when available, or builds pgvector from source for the detected PostgreSQL major version

reads protected PostgreSQL `pg_hba.conf` through sudo before inserting the local MemoryDB trust stanza

defaults native Gateway auth to password mode with rate limiting and explicit Control UI origins

writes a user-service drop-in so `OPENCLAW_WORKSPACE` and `SQL_MEMORY_MAP` survive Gateway service restarts

Updated `scripts/first_run.sh` so PostgreSQL 14 hosts can apply newer pg_dump output by filtering unsupported `transaction_timeout` and psql guard meta commands before schema replay.

Populated base materialized recall views before fast/derived refresh functions so first-run setup does not fail on unpopulated materialized-view prerequisites.

Added a public-safe DB logic-rule seed for Standard Ubuntu first-run hardening so the install lessons are part of clean-install structured recall.

## Documentation

Updated the Standard Ubuntu install guide with installer compatibility notes and verification commands for Gateway service MemoryDB environment wiring.
