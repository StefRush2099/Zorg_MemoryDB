# Zorg MemoryDB v1.2.3

Released: 2026-05-07

## Focus

This release hardens executive-assistant email visibility rules so assistant-sent mail does not depend on each individual script remembering to copy the operator.

## Added

- Documented the recommended operator-copy email setting in the base setup guide and `.env.example`.
- Added public-safe executive-assistant guidance that outbound assistant email should visibly CC the configured operator by default.
- Updated templates so new installs carry the operator-copy expectation into workspace rules and memory seeds.

## Changed

- Updated the shared rich email helper template to inject the configured operator CC before message serialization/API send when `OPERATOR_CC_EMAIL` is set.
- Clarified that BCC should be message-specific and explicit, not a silent replacement for the operator visibility rule.

## Privacy

This release contains no private operator address, credentials, message contents, live database rows, transcripts, or private recovery data.
