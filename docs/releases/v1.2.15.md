# v1.2.15 - 2026-05-18

This release corrects Docker TUI startup documentation and promotes the upstream/existing-implementation-first rule into the public-safe Zorg MemoryDB distribution.

## Changed

Docker Compose, Dockge, and Docker run docs removed token guidance for already-installed local paths. This first-pass TUI guidance was superseded by v1.2.16, which distinguishes Gateway-connected Docker TUI startup from embedded local mode.

First-run and existing-workspace upgrade helpers no longer try to start a nonexistent standalone Compose `postgres` service when the current stack uses embedded PostgreSQL inside the OpenClaw/Zorg container.

## Added

Added a hard top-level software rule: before writing docs, config, scripts, patches, add-ons, installers, or code for existing software, start from the original upstream distribution, official docs, GitHub/GitLab sources, Hugging Face assets when relevant, and current authoritative examples.

## Verification

Compared the Docker/TUI correction against official OpenClaw docs and upstream GitHub sources.

Validated shell syntax for changed helper scripts.

Validated Docker Compose configuration.

Verified no stale OpenClaw Docker TUI guidance remains that tells installed local users to pass `--token`.
