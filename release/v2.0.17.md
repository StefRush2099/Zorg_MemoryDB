# Zorg MemoryDB v2.0.17

This release makes the `zorg-db-memory` skill the canonical owner of the
2026-07-15 rule-scope correction. It replaces install-specific backup path
assumptions with `OPENCLAW_WORKSPACE`/`WORKSPACE_DIR` and `OPENCLAW_HOME`,
keeps public/core rules separate from private operator overlays, and collapses
repeated markdown fragments into canonical active structured rules while
retaining source provenance.

The release also queues the affected canonical rules for semantic refresh and
retains bounded dynamic weights and recall hints. The LAN Command Chat gauge
uses package metadata and is versioned at `2.0.17`, matching the root package.

Private memory, credentials, database contents, local connection maps, retired
runtime artifacts, and generated build output are excluded.
