# v1.1.2 — Integrated OpenClaw startup cleanup

This release removes confusing user-facing database credential and Gateway shared-secret setup from the public install path. Zorg MemoryDB is documented and packaged as an integrated OpenClaw build: start OpenClaw, and memory is already wired.

## Changed

- Removed database credential environment fields from Docker/Dockge examples.
- Removed Gateway shared-secret examples from Docker run, Docker Compose, Dockge, Ubuntu, README, and quickstart docs.
- `sql_memory_map.json` generation no longer writes a database credential field.
- Docker/Dockge internal PostgreSQL initializes with local trust access inside the single OpenClaw/Zorg container.
- Docs now describe the memory database as an internal OpenClaw runtime detail under `/home/openclaw/.openclaw`, not as a separate install.

## Compatibility

Supported install paths remain:

1. Docker run / GHCR
2. Docker Compose
3. Dockge using lowercase `zorg_memorydb`
4. Standard Ubuntu

Docker and Dockge remain one self-contained OpenClaw/Zorg container with internal PostgreSQL.
