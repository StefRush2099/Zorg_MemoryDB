# v1.2.20 - 2026-05-18

This release reorganizes the install, upgrade, and TUI documentation so readers see the native path first, then Docker Compose, then Dockge, then Docker run.

Reordered README and quickstart install paths to standard Ubuntu, Docker Compose, Dockge, then Docker run.

Reordered the upgrade runbook to match the install sequence and added native pre-upgrade verification before the Docker paths.

Split TUI guidance into standard Ubuntu first, then Docker Compose/Dockge, then Docker run.

Removed redundant public-repository sanitization wording from current user-facing install and release-process docs.
