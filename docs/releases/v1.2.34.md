# v1.2.34 - Docker LAN Chat Port Range

## Changed

Docker Compose, Dockge, and Docker-run installs now keep LAN command chat inside the main OpenClaw/Zorg container on internal port `3001`.

Docker hosts now publish LAN command chat through `LAN_CHAT_PUBLISHED_PORTS`, default `8080-8180`, so multiple OpenClaw/Zorg installs on one Docker or Dockge host can each receive a different external LAN chat port.

Beginner docs now explain how to find the selected external LAN chat port with `docker compose port openclaw 3001` or `docker port <container> 3001/tcp`.

## Verification

Docker Compose config must show only the main service named `openclaw` by default, with `openclaw-cli` available only under the `cli` profile.

Docker Compose config must publish Gateway target port `18789` through host range `18789-18889` and LAN chat target port `3001` through host range `8080-8180`.

Active Docker/Dockge docs must not tell users to run LAN command chat as a separate Docker app or assume fixed external host port `3001`.
