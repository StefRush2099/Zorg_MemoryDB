# Zorg MemoryDB v3.0.1

This patch release publishes the live semantic capture repair. It preserves
the existing rule-feedback procedure and connects captured operational rows
to additive semantic/ANN queue work through lightweight PostgreSQL triggers.

Source occurrences, payloads, code records, decisions, errors, corrections,
external actions, verifications, and event links remain complete. Queue
deduplication is limited to derived work; source records are not pruned.

The release also keeps the LAN Command Chat package version synchronized and
adds a database-owned trigger status view for installation verification.
