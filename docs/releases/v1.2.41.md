# v1.2.41 - Lower-Priority Rule Migration And Recall Noise Filtering

## Changed

Added `db/lower_priority_rule_migration_and_recall_filter_2026_05_20.sql`.

The migration promotes rule-like lower-priority archived rows into `zorg_logic_rules` with preserved `normal`, `medium`, and `low` priorities.

Medium memory-recall rows can be excluded from that migration when those rules are already represented by structured DB rules.

Default recall materialized views now exclude noisy archived markdown/session transcript categories while preserving the original rows in `zorg_memory`.

`zorg_search_memory` now sorts by source rank and priority rank, including explicit `normal` and `low` handling.

The DB-memory enforcer now disables the bundled OpenClaw `session-memory` hook to prevent new `memory/*.md` session-summary files in DB-only installs.

## Verification

Run the migration only after a private PostgreSQL backup.

Verify `zorg_logic_rules` contains the migrated lower-priority rows.

Verify `zorg_memory_search_mv` no longer exposes noisy archived markdown/session categories as default `zorg_memory` recall rows.

Verify representative natural-language recall returns structured rules before archival source rows.
