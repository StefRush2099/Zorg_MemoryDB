# v1.2.19 - 2026-05-18

This release corrects the Docker Compose TUI instructions so users attach to the already-running OpenClaw/Zorg container instead of starting a one-shot helper container.

## Changed

Docker Compose and Dockge TUI docs now use `docker compose exec -it openclaw openclaw tui`.

Current docs explicitly say not to start a one-shot Compose helper container, use `openclaw chat`, or use `--local` for the installed Docker Compose Gateway TUI path.

Quickstart and upgrade verification now use `docker compose exec openclaw openclaw doctor` instead of a one-shot helper container.

## Verification

Rechecked official OpenClaw TUI docs first: `openclaw tui` connects to the Gateway, while `chat` and `--local` are embedded local mode.

Verified local docs no longer contain one-shot Docker Compose TUI/chat/dashboard helper commands as current guidance.

Validated `docker compose --profile cli config`.
