# Zorg MemoryDB v1.2.48

## Fixed

- Hardened the native Linux install script so prerequisite repair runs before OpenClaw or npm install work begins.
- Added automatic Node.js validation and upgrade for hosts with missing or too-old Node. OpenClaw now requires Node >= 22.19.0, so Debian and Ubuntu hosts use NodeSource Node 22 before npm runs.
- Added package-manager-aware base dependency installation for apt, dnf, yum, zypper, apk, pacman, and brew, with early failure when the installer cannot repair an unsupported host automatically.
- Made PostgreSQL startup/reload use the available service manager instead of assuming only systemd's plain `postgresql` unit exists.

## Verified

- Ran shell syntax validation for the updated native install script.
