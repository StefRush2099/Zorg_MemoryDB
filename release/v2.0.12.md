# Zorg_MemoryDB v2.0.12

## ANN/vector recall bootstrap

- Registers the ANN model slot, source queue, query cache, workers, and maintenance jobs on clean install and upgrade.
- Uses the supported local Ollama model `nomic-embed-text:latest` by default.
- Updates existing recall functions so the router and direct SQL calls use the same provider/model defaults.
- Preserves existing source memory and makes migration reruns idempotent.
